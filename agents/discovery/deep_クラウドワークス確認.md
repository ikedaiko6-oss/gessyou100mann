# クラウドソーシング案件調査:「事故物件×お得さ×心霊体験」診断ツールのレッドオーシャン化リスク確認

調査日: 2026-06-26
調査方法: WebSearch(Google検索)による crowdworks.jp / lancers.jp 公開ページの検索エンジンインデックス確認

## 前提となる限界(重要)

クラウドワークス・ランサーズの個別案件ページの多くは**検索エンジンにインデックスされていない、または募集終了後に非公開化される**ため、WebSearchで「見つからない」ことは「存在しない」ことの証明にはならない。本調査は「検索で確認できた範囲」の報告であり、悉皆調査ではない。

---

## 1. 「事故物件」×「ライティング案件」の直接検索

検索クエリ: `crowdworks.jp 事故物件 記事作成` / `crowdworks 事故物件 ライティング 案件`

**結果: 「事故物件」をテーマとした記事作成・ライティング募集案件は検索では確認できなかった。**

ヒットしたのは以下のような無関係なページのみ:
- [ライティング・記事作成のご依頲なら「クラウドワークス」](https://crowdworks.jp/static/lp/writing/)(カテゴリトップ、事故物件に限定せず)
- [記事・Webコンテンツ作成の仕事・求人を探す](https://crowdworks.jp/public/jobs/category/37)(カテゴリ一覧)
- [【継続あり】交通事故に関するKWの記事執筆可能な方を募集します。](https://crowdworks.jp/public/jobs/9264035)(「事故」というキーワードが一致しただけで、テーマは交通事故。事故物件とは無関係)

→ 「事故物件」をテーマ名として明示した募集案件は1件も見つからなかった。

## 2. lancers.jp での確認

検索クエリ: `lancers.jp 事故物件 記事`

**結果: ランサーズでも「事故物件」をテーマとした記事制作案件は検索で確認できなかった。**

ヒットしたのは以下:
- [記事制作 - フリーライターに依頼するなら | ランサーズ](https://hosting.lancers.jp/lp/writing/)(サービストップページ)
- 検索結果に紛れて[Game*Sparkの記事](https://www.gamespark.jp/article/2026/06/22/168299.html)(『日本事故物件監視協会3』というゲームのニュース記事。クラウドソーシング案件ではない)が出たが、これは無関係。

→ ランサーズでも事故物件特化の案件は見当たらなかった。

## 3. 「心霊」単体での確認(重要な発見)

検索クエリ: `クラウドワークス 心霊 ライター募集`

**結果: 「心霊」「オカルト」「怖い話」をテーマにしたライター募集案件は複数実在することを確認した。**

- [【1200文字以上文字数上限なし】心霊体験や怪奇現象など幽霊体験談の執筆のお仕事](https://crowdworks.jp/public/jobs/7255551)
- [【オカルト大好きな人歓迎！】怖い話を執筆できる方募集！【心霊系、ヒトコワ系どちらでもOK】](https://crowdworks.jp/public/jobs/12002350)
- [【オカルト、心霊大好きな人歓迎！】ホラー作家さん募集！【働き方により継続発注あり】](https://crowdworks.jp/public/jobs/11035254)
- [心霊 ゆっくり解説 ライター様募集](https://crowdworks.jp/public/jobs/11631705)(YouTube向けシナリオ・脚本制作)

これらは「心霊体験談」「怖い話」を素材として集める・執筆させる案件であり、女性向けメディア運営企業や、ゆっくり解説系YouTube運営者からの継続発注も含まれる。つまり**「心霊」コンテンツ自体の需要・発注実績は明確に存在する**。ただしテーマは「心霊体験の収集・執筆」であり、「事故物件の物件情報×お得度合いを心霊リスクと組み合わせて診断する」という今回の企画の核(不動産情報と心霊要素の掛け算による意思決定支援)とは異なる。

## 4. 「不動産」ジャンル全般の市場感(参考情報)

検索クエリ: `クラウドワークス 不動産 ライティング 単価 案件` / `crowdworks.jp 不動産 記事作成 募集`

**結果: 不動産ジャンルのライティング案件自体は一定数・継続的に存在し、単価は文字単価2.0〜5.0円台と比較的高水準。**

- [不動産業のスキルが必要な仕事・案件を探す](https://crowdworks.jp/public/jobs/skill/3173)(カテゴリページ。常時複数案件が掲載される枠)
- [【不動産投資家限定｜文字単価3.0～5.0円以上】不動産メディアを本気で伸ばせる専属SEOライター募集](https://crowdworks.jp/public/jobs/12972972)
- [【文字単価2.0円〜】不動産関連Webメディアのコラム記事ライターを募集いたします！](https://crowdworks.jp/public/jobs/12268525)
- [不動産コラムのWEBライター募集](https://crowdworks.jp/public/jobs/11137359)

一般的なライティング案件の単価が0.4〜2円/字程度とされる中、不動産系は2.0〜5.0円/字と高単価帯。不動産メディア運営企業がSEOライターを継続的に募集していることから、不動産ジャンル自体は企業が投資している市場であることが分かる。ただし、これらの案件はいずれも「事故物件」や「心霊」要素を含む形跡はなく、通常の不動産投資・住宅選び系コラムである。

## 結論(150字程度)

「事故物件」単体の記事作成案件はクラウドワークス・ランサーズの検索では確認できず、企業に気づかれた形跡は薄い。しかし「心霊」コンテンツ自体は複数の企業が継続発注しており未開拓ではない。「事故物件×お得さ×心霊診断」という掛け算の企画そのものが案件化されている証拠はなく、その意味では手つかずと言えそうだが、検索インデックスの限界上、確定的な裏付けにはならない。
